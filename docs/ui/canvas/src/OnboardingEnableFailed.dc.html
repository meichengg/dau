Dấu không cần quyền điều khiển máy Mac.

Chưa bật được Dấu

macOS chưa thêm Dấu vào nguồn đầu vào. Có thể hộp thoại không hiện, hoặc yêu cầu đã bị từ chối.

  1. 1Bấm Thử lại, rồi bấm Allow khi System Settings hỏi.
  2. 2Hoặc tự thêm: System Settings › Keyboard › Input Sources › Edit… › + › Vietnamese › Dấu, rồi bấm Add.
  3. 3Không thấy Dấu trong danh sách đó: đăng xuất rồi đăng nhập lại một lần (menu Apple › Log Out), rồi mở lại Dấu.
