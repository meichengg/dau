Báo ứng dụng gõ lỗi

Bạn xem lại trước khi gửi. Báo lỗi trên GitHub được đăng công khai; không có tài khoản GitHub thì sao chép nội dung và gửi qua email.

Ứng dụng không chọn được Dấu?Ứng dụng đó có thể còn giữ danh sách nguồn đầu vào cũ. Đăng xuất ( › Log Out) rồi đăng nhập lại một lần, sau đó thử lại; thoát rồi mở lại ứng dụng thì chưa đủ. Vẫn lỗi thì gửi báo lỗi bên dưới.
