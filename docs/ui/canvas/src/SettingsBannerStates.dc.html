Banner “Dấu chưa được bật” — sau khi bấm Bật lại

Đang chờ
Đang chờ bạn bấm AllowHộp thoại nằm trong cửa sổ System Settings. Bấm Allow để bật Dấu.
Chưa bật được
Chưa bật được DấuBấm Thử lại rồi Allow, hoặc tự thêm: System Settings › Keyboard › Input Sources › Edit… › + › Vietnamese › Dấu.
Đã bật
Đã bật DấuChọn Dấu trên menu nguồn đầu vào, hoặc nhấn ⌃Space để chuyển giữa Dấu và “U.S.”
